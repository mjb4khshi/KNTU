جلسه ۱: از فلوچارت تا کد — جمع دو عدد¶

🎯 هدف جلسه¶

آشنایی با ساختار پایه یک برنامه: ورودی → پردازش → خروجی

فلوچارت‌هایی که جلسات قبل کشیدیم رو امروز تبدیل به کد واقعی می‌کنیم، هم در پایتون هم در ++C.

📝 مثال ۱: جمع دو عدد ثابت¶

فلوچارت: شروع → عدد اول ۵ → عدد دوم ۲ → جمع → نمایش نتیجه → پایان

🔷 پیاده‌سازی در پایتون¶

# تعریف دو عدد به صورت ثابت
a = 5
b = 2

# محاسبه جمع
sum_result = a + b

# نمایش نتیجه
print("حاصل جمع:", sum_result)
print(f"{a} + {b} = {sum_result}")

حاصل جمع: 7
5 + 2 = 7

پیاده‌سازی در سی++¶

#include <iostream>
using namespace std;

int main() {
    // تعریف دو عدد به صورت ثابت
    int a = 5;
    int b = 2;
    // محاسبه جمع
    int sum_result = a + b;
    // نمایش نتیجه
    cout << "حاصل جمع: " << sum_result << endl;
    cout << a << " + " << b << " = " << sum_result << endl;
    return 0;
}

مثال ۲: محاسبه محیط و مساحت مستطیل (با ورودی از کاربر)¶

🎯 هدف¶

گرفتن ورودی از کاربر در هر دو زبان و انجام محاسبه — این‌بار دیگه اعداد ثابت نیستن، هرچی کاربر وارد کنه حساب می‌کنیم!

فلوچارت: شروع → دریافت طول → دریافت عرض → محاسبه محیط → محاسبه مساحت → نمایش نتایج → پایان

🔷 پیاده‌سازی در پایتون¶

# گرفتن طول و عرض از کاربر
# نکته: input() همیشه رشته برمی‌گردونه، پس float() می‌کنیم
length = float(input("طول مستطیل را وارد کنید: "))
width = float(input("عرض مستطیل را وارد کنید: "))

# محاسبات
perimeter = 2 * (length + width)    # محیط
area = length * width               # مساحت

# نمایش نتایج
print("\n--- نتایج ---")
print(f"محیط مستطیل: {perimeter}")
print(f"مساحت مستطیل: {area}")

طول مستطیل را وارد کنید:  3
عرض مستطیل را وارد کنید:  4

--- نتایج ---
محیط مستطیل: 14.0
مساحت مستطیل: 12.0

پیاده‌سازی در سی++¶

#include <iostream>
using namespace std;

int main() {
    // تعریف متغیرها
    float length, width;
    // گرفتن ورودی از کاربر
    cout << "طول مستطیل را وارد کنید: ";
    cin >> length;
    cout << "عرض مستطیل را وارد کنید: ";
    cin >> width;
    // محاسبات
    float perimeter = 2 * (length + width);    // محیط
    float area = length * width;               // مساحت
    // نمایش نتایج
    cout << "\n--- نتایج ---" << endl;
    cout << "محیط مستطیل: " << perimeter << endl;
    cout << "مساحت مستطیل: " << area << endl;
    return 0;
}

ساختارهای شرطی در پایتون — if و else و elif¶

🎯 هدف¶

در برنامه‌نویسی همیشه مسیر اجرا مستقیم نیست. گاهی باید تصمیم بگیری:
- اگر این شرط برقرار بود → فلان کار رو بکن
- در غیر این صورت → یه کار دیگه بکن

این دقیقاً همون چیزی‌ست که توی فلوچارت با لوزی (شرط) نشون می‌دادیم.

🧠 ساختار کلی در پایتون¶

if شرط_اول:
    # اگر شرط اول درست بود، اینجا اجرا میشه
elif شرط_دوم:
    # اگر شرط اول غلط بود ولی شرط دوم درست بود، اینجا
else:
    # اگر هیچ‌کدوم از شرط‌ها درست نبود، اینجا

📌 نکات کلیدی¶

نکته توضیح
دندانه‌گذاری (Indentation) حتماً ۴ فاصله یا یک Tab بذارید. پایتون بهش حساسه!
: یادتون نره آخر هر if و elif و else حتماً دونقطه بذارید
elif = مخفف else if می‌تونی چندتا شرط پشت سر هم بذاری
else اختیاریه می‌تونی فقط if تنها هم داشته باشی
اولین شرط درست اجرا می‌شه بقیه شرط‌ها دیگه چک نمی‌شن

🔷 مثال ساده: چک کردن مثبت یا منفی¶

number = float(input("یک عدد وارد کن: "))

if number > 0:
    print("عدد مثبته! 😊")
elif number < 0:
    print("عدد منفیه! 😟")
else:
    print("عدد صفره! 😐")

مثال ۳: پیدا کردن ماکسیمم دو عدد با if-else¶

🎯 مسئله¶

کاربر دو عدد وارد می‌کند، برنامه عدد بزرگ‌تر را مشخص کند.

فلوچارت: شروع → دریافت a → دریافت b → اگر a > b → چاپ a → در غیر این صورت → چاپ b → پایان

🔷 پیاده‌سازی در پایتون¶

# گرفتن دو عدد از کاربر
a = float(input("عدد اول: "))
b = float(input("عدد دوم: "))

# پیدا کردن ماکسیمم با if-else
if a > b:
    print(f"عدد بزرگ‌تر: {a}")
elif b > a:
    print(f"عدد بزرگ‌تر: {b}")
else:
    print("هر دو عدد با هم برابرند! 🤝")

نمونه اجرا (ورودی: ۷ و ۱۲):

عدد اول: 7
عدد دوم: 12
عدد بزرگ‌تر: 12.0

نمونه اجرا (اعداد برابر):

عدد اول: 5
عدد دوم: 5
هر دو عدد با هم برابرند! 🤝

🔶 پیاده‌سازی در ++C¶

#include <iostream>
using namespace std;

int main() {
    float a, b;
    cout << "عدد اول: ";
    cin >> a;
    cout << "عدد دوم: ";
    cin >> b;
    // پیدا کردن ماکسیمم با if-else
    if (a > b) {
        cout << "عدد بزرگ‌تر: " << a << endl;
    }
    else if (b > a) {
        cout << "عدد بزرگ‌تر: " << b << endl;
    }
    else {
        cout << "هر دو عدد با هم برابرند!" << endl;
    }
    return 0;
}

نمونه اجرا (ورودی: ۷ و ۱۲):

عدد اول: 7
عدد دوم: 12
عدد بزرگ‌تر: 12

📊 مقایسه if-else در پایتون و ++C¶

ویژگی Python 🐍 ++C ⚙️
نوشتن شرط if a > b: if (a > b)
پرانتز شرط لازم نیست حتماً بذارید
بلوک کد با دندانه‌گذاری (فاصله) مشخص می‌شه با آکولاد {} مشخص می‌شه
elif / else if elif else if (دو کلمه جداجدا)
علامت مساوی == ==

🧠 چرا سه حالت در نظر گرفتیم؟¶

حالت شرط توضیح
a > b if عدد اول بزرگ‌تره
b > a elif عدد دوم بزرگ‌تره
a == b else هیچ‌کدوم بزرگ‌تر نیستن، برابرن

اگه else رو نمی‌ذاشتیم و دو عدد برابر می‌دادیم، برنامه هیچ‌چیزی چاپ نمی‌کرد! 😐

⚡ نکته: در پایتون از and بجای && و از or بجای || استفاده می‌شود.

و بازه‌ها را می‌توان به صورت زنجیره‌ای نوشت:
if 10 < score <= 15: یعنی score بین ۱۰ و ۱۵ (بدون نیاز به and)

# دریافت نمره از کاربر
score = float(input("نمره خود را وارد کنید (از ۰ تا ۲۰): "))

# گریدبندی نمره
if 0 <= score <= 5:
    grade = "F (ضعیف)"
elif 5 < score <= 10:
    grade = "D (نیاز به تلاش بیشتر)"
elif 10 < score <= 15:
    grade = "C (متوسط)"
elif 15 < score <= 20:
    grade = "A (عالی)"
else:
    grade = "نمره نامعتبر! (باید بین ۰ تا ۲۰ باشد)"

# نمایش نتیجه
print(f"نمره شما: {score}")
print(f"گرید: {grade}")

نمره خود را وارد کنید (از ۰ تا ۲۰):  20

نمره شما: 20.0
گرید: A (عالی)

مقداردهی چند متغیر در پایتون¶

🎯 هدف¶

در پایتون می‌توانیم چند متغیر را هم‌زمان و در یک خط مقداردهی کنیم. این قابلیت پایتون رو از خیلی زبان‌ها

۱. مقداردهی مساوی (همه یک مقدار بگیرند)¶

# هر سه متغیر مقدار یکسان می‌گیرند
x = y = z = 10

print(x)  # 10
print(y)  # 10
print(z)  # 10

💡 نکته: همه متغیرها به یک مقدار در حافظه اشاره می‌کنند. برای اعداد و رشته‌ها مشکلی نیست، ولی برای لیست‌ها باید حواست باشه!

۲. مقداردهی نامساوی (هرکدام مقدار متفاوت)¶

# هر متغیر مقدار خودش را می‌گیرد
a, b, c = 1, 2, 3

print(a)  # 1
print(b)  # 2
print(c)  # 3

۳. جابجایی دو متغیر بدون متغیر کمکی¶

این یکی از قشنگ‌ترین ویژگی‌های پایتونه:

x = 5
y = 10

# جابجایی در یک خط!
x, y = y, x

print(x)  # 10
print(y)  # 5

✨ معجزه پایتون: در ++C برای این کار به یک متغیر موقت (temp) نیاز داریم، ولی پایتون در یک خط انجامش می‌ده!

📊 مقایسه با ++C¶

کار Python 🐍 ++C ⚙️
مقداردهی مساوی x = y = z = 5 باید خط‌به‌خط بنویسی
مقداردهی نامساوی a, b, c = 1, 2, 3 بازم خط‌به‌خط
جابجایی x, y = y, x نیاز به متغیر کمکی داره
Unpacking پشتیبانی عالی نداره

استانداردهای نام‌گذاری متغیرها در پایتون¶

🎯 هدف¶

انتخاب اسم خوب برای متغیر، نصف خوانایی کد است. پایتون قوانین مشخصی برای نام‌گذاری دارد که باید رعایت شوند، و البته توصیه‌هایی هم برای زیباتر شدن کد دارد.

📏 قوانین اجباری (اگر رعایت نکنی → ارور!)¶

قانون مثال درست ✅ مثال غلط ❌ خطا
فقط حروف، عدد و آندرلاین name, score_1 na@me, my-var SyntaxError
با عدد شروع نشود var1, _name 1var, 123 SyntaxError
کلمات کلیدی پایتون نباشند student if, class, for SyntaxError
بین حروف فاصله نباشد user_name user name SyntaxError

🔑 کلمات کلیدی ممنوعه در پایتون¶

این کلمات را نمی‌توانید به عنوان نام متغیر استفاده کنید:

False   await   else    import  pass
None    break   except  in      raise
True    class   finally is      return
and     continue for    lambda  try
as      def     from    nonlocal while
assert  del     global  not     with
async   elif    if      or      yield

💡 ترفند: با دستور import keyword و print(keyword.kwlist) لیست کامل را ببینید.

🎨 قراردادهای پیشنهادی (PEP 8 — Style Guide)¶

نوع نام‌گذاری سبک مثال کاربرد
snake_case 🐍 حروف_کوچک_با_آندرلاین student_name متغیرها و توابع
UPPER_CASE 📢 حروف_بزرگ_با_آندرلاین MAX_SCORE, PI ثابت‌ها
PascalCase 🏛️ حرف_اول_بزرگ_هر_کلمه StudentRecord نام کلاس‌ها
_underscore 🤫 شروع با آندرلاین _private_var متغیرهای داخلی/خصوصی

✨ نمونه‌های خوب و بد¶

# ❌ بد — نام‌های بی‌معنی
a = "علی"
b = 20
x1 = 3.14

# ✅ خوب — نام‌های با معنی
student_name = "علی"
student_age = 20
pi_value = 3.14

# ❌ بد — مخفف‌های نامفهوم
std_nm = "علی"
calc_avg = 17.5

# ✅ خوب — کامل و خوانا
student_name = "علی"
calculated_average = 17.5

📊 مقایسه با ++C¶

ویژگی Python 🐍 ++C ⚙️
حساسیت به حروف بزرگ/کوچک name ≠ Name (حساسه) name ≠ Name (حساسه)
کلمات کلیدی حدود ۳۵ کلمه بیش از ۹۰ کلمه
طول نام محدودیت عملی نداره محدودیت عملی نداره
یونیکد (فارسی) مجازه معمولاً پشتیبانی نمی‌شه
قرارداد رسمی snake_case camelCase یا PascalCase

🧠 خلاصه یک‌خطی¶

🎯 قاعده طلایی: نام متغیر باید آنقدر گویا باشد که یک غریبه بدون توضیح اضافه بفهمد چه چیزی در آن ذخیره شده. نه آنقدر بلند که حوصله‌سربر شود، نه آنقدر کوتاه که مبهم باشد.
