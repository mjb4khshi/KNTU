## camel case
یه استاندارد جاوا اسکریپت واسه نامگذاری متغیره که بخش اول رو با حرف کوچیک و بعد جداسازی هر قسمت رو با یه حرف بزرگ انجام میدیم
مثلا یه چنین چیزی:
```JS
let firstName = "mammad";
let mammadSisterName= "zahra";
```

## محدودیت نامگذاری:
نام متغیر نباید با عدد شروع بشه توی جی اس.
ولی میتونه عدد وسطش بیاد 
از آندر اسکور _ میشه استفاده کرد
از $ هم میشه استفاده کرد
ولی باقی توکن ها غیر مجازن.
از نام های رزرو شده هم نباید استفاده کنی مثلا new . function و اگه خواستی اوکی شه با دلار و آندر اسکور قبلش تغییر بدی و با کلمه رزرو شده تمایز بدی
name هم رزرو شده ولی قانونیه ولی بازم بهتره استفاده نکنی از نیم خالی
اسم متغیر نباید با حرف بزرگ شروع شه ولی قانونیه، اما نباید استفاده شه اصولا چون واسه برنامه نویسی شی گرا مورد استفاده قرار میگیره و خب استاندارد نیست که با حرف بزرگ شروع کنی.
برای اعدادی که میدونیم همیشه ثابتن طی پروژه و تغییری نمیکنن از حروف تماما بزرگ استفاده میکنیم مثلا عدد پی:
```JS
let PINUMBER = 3.141522
```
منطقا باید اسم متغیرهات توصیف خوبی بدن از مقدار متغیر 
مقدار رشته رو حتما تو نقل قول تکی یا دوتایی بذار که مفسر بفهمه و با متغیر اشتباه نگیره.
## تعویض مقدار متغیر
به سادگی قابل انجامه منتها حتما حواست باشه که let نذاری دیگه قبلش ارور سینتکس میده چون اصولا تو هر اسکوپ فقط یه بار میتونه که با لت متغیر تعریف بکنی و واسه تعویض مقدار دیگه let نباس بذاری.
## 🔍 تفاوت `null` و `undefined` در جاوااسکریپت

| ویژگی          | `undefined`                                  | `null`                                         |
| -------------- | -------------------------------------------- | ---------------------------------------------- |
| تعریف          | وقتی متغیر تعریف شده ولی مقدار نگرفته        | وقتی عمداً می‌گیم "هیچ مقداری نداره"           |
| رفتار پیش‌فرض  | خود جاوااسکریپت می‌ده                        | خودمون دستی می‌دیم                             |
| نوع (`typeof`) | `"undefined"`                                | `"object"` (عجیب ولی واقعی!)                   |
| کاربرد         | برای چک کردن مقداردهی نشده                   | برای خالی کردن یا ریست کردن متغیر              |
| در شرط‌ها      | معمولاً false ولی قابل بررسی با `==` و `===` | معمولاً false ولی با `==` برابر با `undefined` |

## کلمات کلیدی let, const, var
let:تعریف متغیر در شرایطی که ممکنه مقادیر داخل متغیر تغییر کنه
const:متغیر ثابت مثلا عدد پی یا سال تولد یه نفر و نمیشه دیگه جایی بهش مقدار جدید داد و ارور میده مفسر
و نمیشه const رو تعریف نشده بذاری حتما باید مقدار بدی چون خب بعدا که ویرایش نمیشه پس ارور میده و خطاعه.
به جهت کد تمیز حتما حتما به طور پیشفرض const بذار متغیر رو و اگه مطمئن بودی قراره حتما تغییر کنه let بذار
راجع به var هم فقط بدون بنا به دلایل فنی بهتره ازش استفاده نکنی دلایلشم جلوتر میفهمی و البته که منسوخه واسه قبل ES6 هستش در واقع و فقط می‌خونیم که بدونیم چطوریه داستانش ولی خب کلا بخوای بدونی مثل let تعویض میشه و ثابت نیست.
