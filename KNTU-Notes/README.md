## 🚀 ویژگی‌های فنی و طراحی قالب سرو (Sarv UI)

- **گراف شبکه تعاملی ابسیدین (Knowledge Graph):**
  - شبیه‌سازی فیزیکی نیروی لحظه‌ای (Force-directed simulation) روی بوم Canvas.
  - پشتیبانی کامل از تاچ، پن (Pan) تک‌انگشتی و زوم دوانگشتی (Pinch-to-zoom) در اندروید و iOS.
  - تفکیک هوشمند نودهای نوت داخلی از پیوندهای خارجی و کارت‌های منابع پیوست (با استایل متمایز سبز و یال‌های خط‌چین).
  - رفع کامل پرش نود هنگام درگ کردن و تمایز کلیک خالص از درگ.
  - حذف لینک‌های تصنعی زنجیره‌ای و نمایش اتصالات مفهومی واقعی یادداشت‌ها.
- **سیستم برچسب‌ها و ایندکس تگ‌ها (Tag Engine):**
  - شناسایی خودکار برچسب‌های ابسیدین (`#tag`) بدون تداخل با تیترهای هدر (`# Heading`) یا کدهای هگز.
  - رندر کپسولی استایل‌دار (`.sarv-tag`) با هدایت مستقیم به صفحه برچسب‌ها.
  - ابر برچسب‌ها (Tag Cloud) با دسته‌بندی و فیلتر زنده بر اساس فراوانی.
- **تایپوگرافی و زیبایی‌شناسی اختصاصی:**
  - فونت چشم‌نواز آراد (Arad VF) با وزن‌های بهینه‌سازی‌شده برای مطالعه طولانی.
  - پالت رنگی سالید (Pure Solid Aesthetics) بدون گرادیان‌های غیرطبیعی.
  - دکمه‌های ۳بعدی لمسی برجسته (`.btn-relief`).
  - نوار پیشرفت مطالعه بالا و برآورد زمان مطالعه هر نوت.
  - پشتیبانی از فرمول‌های ریاضی پیچیده با MathJax 3 و نمودارهای تعاملی Mermaid.

## 🛠️ راهنمای اجرا و توسعه لوکال

### پیش‌نیازها
- پایتون نسخه 3.10 یا بالاتر
- پکیج‌های مورد نیاز MkDocs:

```bash
pip install mkdocs mkdocs-material pymdownx-superfences mkdocs-awesome-pages-plugin mkdocs-callouts mkdocs-glightbox
```

### اجرای سرور زنده (Live Reload)
جهت مشاهده و ویرایش زنده یادداشت‌ها:
```bash
mkdocs serve -a 0.0.0.0:8000
```
سپس آدرس `http://localhost:8000` را در مرورگر خود باز کنید.

### بیلد نهایی پروژه (تست Strict)
برای اطمینان از عدم وجود هرگونه اخطار یا لینک شکسته:
```bash
mkdocs build --strict
```

### انتشار روی گیت‌هاب پیجز (GitHub Pages)
```bash
mkdocs gh-deploy
```
