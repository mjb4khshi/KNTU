اصطلاح انگلیسی ترجمهٔ فارسی پیشنهادی توضیح
Truthy «دارای ارزش درست» یا «مقدار درست‌شونده» مقداری که وقتی به Boolean تبدیل بشه، true می‌ده
Falsy «دارای ارزش نادرست» یا «مقدار نادرست‌شونده» مقداری که وقتی به Boolean تبدیل بشه، false می‌ده

🧪 مثال‌های رایج:¶

مقادیر falsy (نادرست‌شونده):¶

false
0
""        // رشتهٔ خالی
null
undefined
NaN

مقادیر truthy (درست‌شونده):¶

true
1
"hello"   // هر رشتهٔ غیرخالی
[]        // آرایهٔ خالی هم truthy هست
{}        // آبجکت خالی هم truthy هست

معمولا تبدیل تایپ به بولین به کار نمیاد و در واقع اغلب این ارزش ها با تبدیل ضمنی به کار گرفته میشن
